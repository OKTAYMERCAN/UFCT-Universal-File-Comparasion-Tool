# UFCT (Universal File Comparasion Tool)

UFCT is a lightweight yet powerful utility designed to verify files across different directories and creating report. Whether you need a lightning-fast name check or a bit-by-bit integrity verification, UFCT has you covered.

🚀 Features

Quick Scan: Fast comparison based on filenames.

Deep Scan: High-accuracy comparison using Hash values (Checksums) to ensure file integrity.
  
Backup Verification: Perfect for comparing primary and secondary backup drives to find missing or corrupted files.

Flexible Reporting: Export your results directly to Excel (.xlsx) or OpenDocument (.ods) formats simply by changing the file extension.

🛠 Usage

    python "UFCT [Universal File Comparasion Tool].py" <source_directory_1> <source_directory_2> <report_name.extension>
    
Note: The tool automatically detects the desired format based on the output file extension (e.g., .xlsx or .ods).
